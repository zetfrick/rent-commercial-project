# Сайт по аренде коммерческих помещений

## Запуск
1. Установить Maven и Java 17+.
2. Поместить background.jpg в src/main/resources/static/images/.
3. `mvn clean install`
4. `mvn clean test`
4. `mvn spring-boot:run`
5. Откройть http://localhost:8080
6. Swager UI http://localhost:8080/swagger-ui.html
