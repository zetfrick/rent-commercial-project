# Сайт по аренде коммерческих помещений

## Запуск
1. Установите Maven и Java 17+.
2. Поместите background.jpg в src/main/resources/static/images/.
3. `mvn clean install`
4. `mvn spring-boot:run`
5. Откройте http://localhost:8761

## Тестирование
- Логин: user / password
- Города: Наведите на город → клик для выбора (перезагрузка).
- Каталог: 6 placeholder'ов.

Для расширения: Добавьте БД в future/.
